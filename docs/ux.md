# SOVRN — UX Principles

## Core Rules

1. ONE ACTION PER SCREEN. Every screen fills the mobile viewport. 
   The user sees one thing and makes one decision. No scroll walls. 
   No competing CTAs. App experience, not website.

2. NEVER START AT ZERO. Progress bar begins at 12% on Q1. 
   Arriving and clicking BEGIN was already step 0.

3. DARK TO LIGHT. Screens 1-3 are dark (the descent into self). 
   Screen 4 is warm white (the emergence, the revelation). The 
   crossfade from dark loading to white blueprint IS the visual 
   transformation. This is intentional narrative design.

4. GIVE VALUE BEFORE ASKING. The free blueprint delivers 
   enormous value before any paywall. Reciprocity drives 
   conversion naturally.

5. MAKE USERS BUILD SOMETHING (IKEA Effect). Deep personal 
   questions create emotional investment. By Q7, abandoning 
   the flow means losing something they built.

6. SELL THE OUTCOME, NOT FEATURES. The landing page describes 
   what the user will FEEL and KNOW, not what the app contains.

7. LOSS FRAMING FOR PAYWALL. "Without the daily OS, your shadow 
   pattern reactivates within 72 hours" is stronger than "Get 
   daily personalized guidance."

8. CHART INSIGHT BETWEEN DATA AND DEPTH. After birth data (Q1-Q4), 
   show the Sun archetype reveal before the deep questions (Q5-Q7). 
   This builds trust: the system already KNOWS something.

## Screen Flow

Screen 1 → Landing (dark): Headline, subheadline, one red CTA
Screen 2 → Quiz (dark): One question per screen, 8 total, 
  chart reveal between Q4 and Q5
Screen 3 → Loading (dark): Rotating messages, ember wave dots, 
  constellation. Stays until first streaming chunk arrives.
Screen 4 → Blueprint (warm white): Streaming text parsed into 
  section cards. Core quote, blinking cursor, auto-scroll.
Screen 5 → Post-Blueprint CTA (warm white): Download + 
  Begin Your Transformation buttons.

## The "Screenshot Moment"
The core quote at the top of the blueprint (before the first 
section card) is designed to be screenshotted and shared. It 
should be the most devastating, accurate, personally resonant 
line in the entire blueprint. Red text on warm white. Centered. 
Large italic serif. This is the viral mechanic.
